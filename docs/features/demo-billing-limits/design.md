# Polar sandbox billing UI

[Docs home](../../README.md) · [Polar sandbox billing](README.md) · [Specification](spec.md)

Preserve existing workspace billing screens in the retained Next.js, Tailwind, and Radix UI.
The checkout return page states that the upgrade is being confirmed, because entitlements wait
for the verified Polar webhook.
The current scope is described in the [feature scope](spec.md). No replacement
visual system or broader redesign is selected by this page.

The [smoke matrix](../../development/smoke-test-matrix.md) identifies the browser
journeys that need actual validation.
