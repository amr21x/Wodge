# Polar sandbox billing

[Docs home](../../README.md) · [Feature index](../../README.md#features)

Provide working Polar sandbox Checkout and customer portal behavior for the portfolio demo through Better Auth's Polar plugin. Polar replaced the earlier Stripe test billing without changing plans, limits or downgrade behavior. This scope introduces no live-payment launch, new plan prices, storage quotas, premium-eligibility rules, or call metering.
