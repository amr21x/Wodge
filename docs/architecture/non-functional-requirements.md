# Current quality scope

[Docs home](../README.md) · [Architecture](README.md)

The current project requires a reliable portfolio showcase, bounded operating cost,
focused structure fixes, global/recoverable errors, and meaningful bug-fix/retest
and validation evidence while retaining the existing product/UI.

The foundation must demonstrate compatible dependency resolution, browser/server
separation, explicit D1 binding injection, and local Worker/import/build behavior.
Backend permission authority remains in place. Exact checked code and actual
Pass/Fail/Unverified results are recorded with limitations.

The [foundation record](../development/backend-foundation.md) and
[baseline](../development/baseline.md) supply those observations. This page adds no
new latency target, uptime guarantee, quota, numerical budget, or delivery deadline.
