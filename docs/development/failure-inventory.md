F-02 through F-21 identify the consumers that consistent global error handling
must cover. Recovery validation must check draft preservation,
retry bounds, loading completion, navigation/focus, and removal of content after
permission loss. Root errors, render errors, API failures, and sync protocol errors
are separate boundaries; one generic toast cannot establish coverage of all four.
