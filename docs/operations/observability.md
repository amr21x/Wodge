# Recorded runtime observations

[Docs home](../README.md) · [Operate Wodge](README.md)

The local foundation work records command output, source hashes, installed versions,
failures, and verification limits in its [evidence record](../development/backend-foundation.md).
It did not deploy a monitoring service or validate production usage and cost.

The current project requires a reliable portfolio demo, recoverable errors, meaningful
validation, and bounded operating cost. Production observations must refer to the
actual reviewed environment and deployment. This page selects no monitoring provider,
retention period, paid service, uptime target, or ongoing maintenance allocation.
