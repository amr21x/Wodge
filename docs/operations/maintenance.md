# Maintenance scope

[Docs home](../README.md) · [Operate Wodge](README.md)

The current work restores a portfolio showcase. This foundation implementation did
not configure recurring maintenance, triage automation, monitoring subscriptions,
backups, or a support schedule.

Additional operational work must be scoped within the current project or approved
separately. Do not carry forward another project's maintenance process, budget,
retention rules, or service commitments.

The [current project scope](../development/documentation.md) and
[local evidence](../development/backend-foundation.md) describe the work performed.
