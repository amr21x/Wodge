# Remote actions and release evidence

[Docs home](../README.md) · [Operate Wodge](README.md)

The current project and local foundation work do not authorize a push, production
deployment, or named release. These require separate owner authorization.

Local checks record the reviewed code and actual results. A future authorized
release/deployment must record its own build identity, approval, execution outcome,
and relevant application validation. The foundation's local Worker/D1 checks do
not establish production readiness.

This page selects no release engine, version number, tag, or plugin policy. See
[current scope](../development/documentation.md) and the
[deployment boundary](runbooks/revival-deployment.md).
