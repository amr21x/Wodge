# Current portfolio principles

[Docs home](../README.md) · [Explore Wodge](README.md)

The [verified project scope](../development/documentation.md) governs the current
portfolio milestone:

- Restore a reliable showcase using the existing product and frontend UI.
- Keep operating cost bounded and distinguish measured usage from assumptions.
- Retain Replicache/Yjs and working test billing (Polar sandbox).
- Make only the necessary backend/auth/runtime compatibility changes.
- Limit initial MCP to permitted discovery, page reading, and task creation/update.
- Temporarily disable calls and hosted generation at UI and backend.
- Record failures and unverified journeys honestly.

Adoption/contributor growth, feature parity, old-data migration, broader UI/tooling
modernization, expanded MCP, and call restoration are outside current execution
scope. No deadline or specific numerical operating budget is established here.
