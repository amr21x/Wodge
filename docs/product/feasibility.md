# Portfolio operating-cost boundary

[Docs home](../README.md) · [Explore Wodge](README.md)

The current project calls for bounded operating cost and a reliable portfolio demo.
It does not establish a numerical monthly budget, paid plan price, provider usage
quota, or delivery schedule through this document.

Calls and hosted generation are to be disabled for the portfolio milestone.
Stripe remains in test mode. No production deployment or remote provisioning was
performed by the local foundation work.

The [foundation evidence](../development/backend-foundation.md) records local
compatibility results and limitations. Production usage and operating cost need
actual measurements for the reviewed deployment; local fixture results establish
neither a provider-plan fit nor a cost forecast.
