# Product and portfolio scope

[Docs home](../README.md) · [Explore Wodge](README.md)

Wodge is the existing local-first collaborative workspace. The current project
restores it as a reliable portfolio showcase with bounded operating cost.

Retain the existing product, frontend UI, Replicache/Yjs, and Stripe test billing.
Migrate backend realtime services to PartyServer/SQLite Durable Objects and auth
to Better Auth/D1. Add minimal member-controlled MCP discovery, page reading, and
task creation/update. Temporarily disable calls and hosted generation in UI and backend.

Necessary Next.js/React and maintained Cloudflare adapter compatibility work is
included while preserving Tailwind/Radix/UI. Broader framework/tooling changes,
custom roles, resource/invitation redesign, expanded MCP, and call restoration
are deferred. Adoption/contributor growth and feature parity are outside the goal.

See the [verified project scope](../development/documentation.md). Local foundation
results are recorded separately from application delivery in the
[foundation evidence](../development/backend-foundation.md).
