# Repository vocabulary

[Docs home](../README.md) · [Explore Wodge](README.md)

- **Workspace:** the top-level collaboration context in the existing application.
- **Team:** an organizational unit within a workspace.
- **Channel:** an existing page, discussion, or room resource.
- **Page:** the collaborative rich-text surface with embedded task views.
- **Thread:** a discussion surface with posts and replies.
- **Room:** a messaging surface; calls are to be disabled for the portfolio milestone.
- **Replicache:** the retained structured local-first synchronization system.
- **Yjs:** the retained collaborative text system.
- **D1:** the database binding supplied explicitly to shared server persistence.
- **MCP:** the member-controlled agent interface scoped initially to discovery,
  page reading, and task creation/update.

The [current scope](../development/documentation.md) defines which migrations are
included. These terms do not introduce redesigned roles, quotas, or ownership rules.
