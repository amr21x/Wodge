# Portfolio UX scope

[Docs home](../README.md) · [Design](README.md)

The current portfolio milestone preserves the existing frontend UI and product
behavior while making necessary dependency, backend, and authentication changes.
A broader redesign is deferred.

Use the existing surfaces for pages/tasks, discussions, membership, and test billing.
Temporarily disable calls and hosted generation at UI and backend. Minimal
member-controlled MCP is limited to the current approved operations.

Evaluate changes against the [current scope](../development/documentation.md) and
[smoke matrix](../development/smoke-test-matrix.md). This page creates no additional
interaction or visual-system requirements.
