# Retained interaction patterns

[Docs home](../README.md) · [Design](README.md)

Reuse existing Next.js, Tailwind, Radix, and editor components for compatibility
changes. Preserve their current product behavior. The foundation does not select
new component primitives, role controls, quotas, invitation flows, or resource UX.

Global/recoverable error handling is separately scoped work. Calls and hosted
generation are to be disabled with corresponding UI and backend behavior.

See [retained design](design-system.md), the [current project scope](../development/documentation.md),
and the [recorded baseline](../development/baseline.md).
