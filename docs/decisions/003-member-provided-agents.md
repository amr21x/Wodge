# Minimal member-controlled agent access

[Docs home](../README.md) · [Decisions](README.md)

The current milestone permits member-controlled MCP discovery, page reading, and task creation/update. Hosted generation has been removed entirely: no editor generation controls, provider endpoints, SDK dependencies, or API key configuration remain. Member-controlled MCP access is separate from hosted model execution. Expanded MCP actions are deferred; no hosted model provider is selected.

See the [verified current scope](../development/documentation.md).
